=== Bugs found and fixed during build (BUGLOG) ===
1. NFA fragment exits stored as int* into a growing std::vector -> dangling on
   realloc. Fixed by recording (state_index, which_field) pairs instead.
2. walk_corpus followed symlinks (is_regular_file does); grep -r and rg do not.
   Caused a 1-file over-return -- safe direction, but not comparable to the
   baseline. Fixed by skipping symlinks.
3. OffRec was {uint64,uint32} = 16 B padded -> 268 MB offset table, 64% of the
   index. Postings are 141 MB so uint32 suffices. Packed to 8 B; index 421->286 MB.
4. and_of/or_of did not flatten, so concat built an O(n^2) nested AND tree.
5. Planner cost estimate returned num_docs() for any non-TRI node, so the
   selectivity cap dropped every nested conjunct. EXPORT_SYMBOL_GPL returned
   13683 candidates instead of 3402. Fixed with a recursive estimate
   (AND -> min of kids, OR -> sum of kids).

=== Task 9 harness: ROOT CAUSE of every "silently dead" oracle run ===
WSL2 shuts the distro VM down seconds after the last wsl.exe session closes. A process detached
with nohup/setsid survives the *session* but not the *VM*, and /tmp is tmpfs -- so the patterns
file and the log both vanished with it. Four runs died this way (20K, 50K x2, 50K-setsid). The
2K tier survived only because it ran in the foreground of a live wrapper. Fix: run in tiers
short enough to keep a wrapper attached for the whole run.

=== Task 9 tier A: 10,000 generated regexes (seed 2), shard index -- FOUND BUG #8 ===
engine            10000 patterns in 713.2 s (14/s)
result            1 MISMATCH, 0 UNSOUND:  pat='(gre|(a)+.[mpwz])'  missing=mxs-pinfunc.h
8. Byte-vs-code-point semantics. RE2 matched 'aßm' (ß = UTF-8 C3 9F): `.` consumes one CODE
   POINT in RE2/ripgrep. The engine's `.` consumed one BYTE, so [mpwz] was tested against 0x9F.
   Synthesis was sound (the file was a candidate); the miss was in the DFA verifier. Fixed as RE2
   does it: any class admitting a byte >= 0x80 (`.`, negated classes) compiles to the UTF-8
   sequence automaton (ASCII | C2-DF 80-BF | E0-EF 80-BF 80-BF | F0-F4 80-BF x3).
   This is the first bug the ORACLE found (bugs 1-7 came from grep-diffing). A 25x larger sample
   than tier 0 found a 1-in-10,000 case that hand-picked kernel queries never exercised.
harness note      the `unsound` check compares candidate COUNT to oracle count, not membership;
                  under-return still surfaces as a MISMATCH with a `missing=` list, so nothing is
                  silently lost -- but the UNSOUND label alone cannot be trusted as "superset held".

post-fix regression  5/5 kernel patterns EXACT vs grep -E; 3-pattern batch smoke byte-identical (825/302, 3542/361, 12/5)
fix verified      one-file index of mxs-pinfunc.h, engine vs google-re2 on 8 probes -- ALL AGREE:
                  (gre|(a)+.[mpwz]) 1/1   a.[mpwz] 1/1   a.m 1/1   a..m 0/0   a[^x]m 1/1
                  Wa.mann 1/1   Wa..mann 0/0   W.ßm 1/1      (nfa_states 9 -> 21 for the UTF-8 automaton)
                  The 0/0 negatives are the proof: `.` now consumes exactly one code point, not one byte and not two.
